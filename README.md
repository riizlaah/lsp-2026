# LSP 2026
Proyek LSP 2026, sebuah web untuk profil sekolah dengan target audiens adalah masyarakat umum.

## Features
- [x] Login & dashboard admin
- [X] CRUD pengumuman
- [x] CRUD artikel/berita (dengan relasi ke galeri)
- [x] CRUD prestasi
- [x] Ganti password admin
- [x] Pengaturan tambahan sederhana (mis. jumlah siswa, jumlah guru, dsb.)
- [x] Pagination

## External Libraries
- Bootstrap 5.3
- Trix (WYSIWYG Editor)
- Feather Icons
- SVG Pan Zoom
- Composer
- nesbot/carbon
- symfony/html-sanitizer
